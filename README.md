# BSCS Lab 01: Advance Programming

This repository contains the tasks and implementations completed for **Lab 01** in Google Colab.

---

##  Topics Covered

1. **Basic Output:** Using the `print()` function to display text and dynamic output.
2. **Variables & Data Types:** Declaring variables, string formatting, and printing values.
3. **Control Flow:** Implementation of conditional statements (`if`, `elif`, `else`).
4. **User Input:** Taking interactive input using the `input()` function.
5. **Functions:** Defining and calling user-defined functions with parameters and return values.
6. **Multithreading:** Executing concurrent tasks using Python's `threading` module.
7. **Multiprocessing:** Running parallel processes using Python's `multiprocessing` module.

---

##  How to Run in Google Colab

You can directly open and run the notebook in Google Colab by clicking the badge inside the repository or following these steps:

1. Open the file `Lab_01.ipynb`.
2. Click on the **"Open in Colab"** button at the top of the notebook.
3. Execute the cells sequentially by pressing `Shift + Enter`.
